# Zombie Outbreak — Godot 3D

Protótipo em desenvolvimento de shooter de sobrevivência contra zumbis, com câmera 3/4 inclinada, movimentação WASD independente da mira e destruição ambiental. Godot 4.x / GDScript.

O código do jogo será desenvolvido neste repositório separado. Integração e verificações automatizadas por GitHub Actions. O [Claude Code Game Studios](https://github.com/Donchitos/Claude-Code-Game-Studios) será usado como **referência metodológica** de planejamento, QA e testes, não como código de jogo copiado.

> Estado: primeira implementação técnica; a qualidade visual e o funcionamento em navegador ainda precisam de validação. Nenhum ativo comercial de terceiros incluído.
